# СМЕНА

Браузерная narrative-sim про первую смену оператора контакт-центра банка «Южный Резерв».

## Запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
npm run preview
```

## Особенности
- Титул, брифинг, рабочий стол оператора, дебрифинг
- Температура клиента, CSAT, AHT, FCR, Compliance
- CRM, База знаний, Скрипт
- 7 кейсов с ветками диалогов
- Эскалация
- Три сложности: Стажёр / Смена / Пик нагрузки
- Автосейв в localStorage
- Data-driven контент
